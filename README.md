# Regresión lineal para predecir el ingreso mensual

Repositorio reproducible: código Python, datos, informe LaTeX, figuras y resultados.

## Estructura
- `data/data.xlsx`: datos de entrada.
- `src/regresion_ingresos_comparacion.py`: script del análisis.
- `informe_regresion_ingresos.tex`: informe LaTeX con figuras integradas.
- `figures/`: gráficas PNG referenciadas por el informe.
- `results/`: métricas y predicciones CSV.
